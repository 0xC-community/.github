## Ese proyecto que traes en la cabeza

Una herramienta que te hace falta. Una idea que anotaste hace meses.
Un proyecto que empezaste y quieres seguir construyendo con alguien.

**En 0xC queremos darle espacio.**

Puedes compartir tu proyecto, encontrar personas que quieran ayudarte
o sumarte al trabajo de alguien más. Si formas parte de otra comunidad,
también queremos conocerte y encontrar algo que podamos hacer juntos.

## Un lugar para empezar y para seguir

| ¿Qué tienes en mente? | Aquí puedes… |
| :--- | :--- |
| **Quiero construir algo** | Compartir tu idea, explicar el problema y encontrar colaboradores. |
| **Mi proyecto necesita una mano** | Mostrar lo que llevas y contar en qué necesitas apoyo. |
| **Quiero colaborar** | Explorar los proyectos y encontrar una tarea donde puedas aportar. |

## También se construye fuera del código

Una explicación clara, una prueba bien hecha, una mejora de diseño
o un error reportado con detalle pueden hacer avanzar un proyecto.

Hay espacio para quienes programan, diseñan, documentan, prueban,
organizan o apenas están encontrando qué les gusta hacer.

**Pregunta con confianza. Comparte lo que sabes.
Reconoce el trabajo de los demás.**

## Empieza por una conversación

**Para colaborar en un proyecto existente:**

1. Explora sus repositorios y lee el README.
2. Consulta sus instrucciones de contribución, si las tiene.
3. Revisa los issues o abre uno para proponer algo.
4. Conversa con el equipo antes de comenzar un cambio grande.

**Para proponer tu proyecto:**

Cuéntanos qué quieres resolver, qué has construido hasta ahora
y qué ayuda buscas. No necesitas tener todas las respuestas,
pero sí explicar por dónde te gustaría empezar.

**Para colaborar entre comunidades:**

Podemos compartir conocimientos, organizar una actividad
o reunir equipos alrededor de un proyecto. Las propuestas
también tienen lugar aquí.
